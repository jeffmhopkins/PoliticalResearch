# How to read this guide

Start with the ballot table, then read one contest at a time. Each race uses the same comparison rows for every candidate. Party is printed as text. This guide does not color a party. An endorsement names the group, its type, the date, and whether the words are the group's own statement or the candidate's site. Money rows use one as-of date for every candidate. Attendance includes the chamber median and does not rank members. A fact-check that was never checked is not a clean rating. A cell that says Not found was searched and not found. The places searched are in the sources addendum.

A small number links to the sources addendum, where the works-cited line, the quote, and the search log live. Tier T1 is an official or primary source. T2 is an established nonpartisan reference. T3 is named journalism. T4 is an advocacy source and is quoted only as that group's view.

One source means one record supports the sentence. An allegation stays labeled as an allegation, with the person's response or a not-found note. This guide does not rank candidates, score them, or recommend a vote. Claims marked disputed or unconfirmed are left out of summaries.

# Glossary {#glossary .back-matter}

Levy
: A levy is a tax or charge put on a ballot for voters to accept or reject.

Nonpartisan race
: A nonpartisan race does not list a party on the ballot. A public voter-registration party, when one is cited, is labeled registered party (race is nonpartisan).

Cash on hand
: Cash on hand is the money a campaign reported still having at the end of a filing period.

Filing period
: A filing period is the date range a finance report covers.

Tier T1
: Tier T1 is a primary or official source.

Tier T2
: Tier T2 is an established nonpartisan reference.

Tier T3
: Tier T3 is named journalism.

Tier T4
: Tier T4 is an advocacy source and is quoted only as that group's view.

Single source
: A single source means the sentence rests on one record.

Allegation
: An allegation is a claim someone has made that this guide has not confirmed.

Not found
: Not found means the listed places were searched and the fact was not in them.
